# Frontend Dashboard (Phase 10)

This directory is designated for the React + Recharts frontend dashboard to be implemented in **Phase 10**.

### Features to be included:
- **Financial Overview Dashboard**: Real-time balance, income, monthly expenses, savings rate, emergency reserve, and debt burden.
- **Analytics & Visualizations**: Interactive expense breakdown charts by category, monthly spending trends, and goal shortfall meters.
- **Transaction Manager**: Table for viewing, adding, editing, and deleting transactions.
- **Conversational AI Assistant**: Chat interface connecting directly to FastAPI GraphRAG backend with grounded evidence cards.
